# راهنمای شخصی‌سازی

این قالب طوری ساخته شده که برای هر مشتری فقط **دو فایل** را عوض کنید، بدون دست‌زدن به هسته.

## ۱) تغییر برند و رنگ
فایل: `frontend/assets/js/config.js`

```js
brand: {
  name: 'نانِ بازار',          // نام فروشگاه
  tagline: 'نانوایی آنلاین',
  first: 'ن',                  // حرف لوگو
  desc: '...',
  copy: '© ۱۴۰۴ نان بازار'
},
contact: { phone: '...', email: '...', addr: '...', hours: '...' }
```

رنگ سازمانی را از `THEMES` یا با اضافه‌کردن یک تم جدید عوض کنید:
```js
export const THEMES = {
  sabz: { name: 'سبز', light: '#2e7d32', dark: '#66bb6a' }
};
```

## ۲) تغییر محصولات و دسته‌ها
فایل: `frontend/assets/js/data.js`

هر محصول یک فراخوانی `P(...)` است:
```js
P('id', 'نام', 'دسته', 'art', hue, قیمت, قیمت_قدیم, موجودی, امتیاز, تعدادنظر, 'برند', {
  desc: 'توضیح',
  specs: [['کلید','مقدار']],
  sizes: ['S','M']
})
```
- `art` نوع تصویر وکتور است (`headphones`, `watch`, `sneaker`, `mug`, `perfume`, `lamp`, `chair`, `camera`, `keyboard`, `bottle`, `sunglasses`, `backpack`, `speaker`, `tshirt`). برای محصول جدید می‌توانید از همین‌ها استفاده کنید یا در `art.js` یکی اضافه کنید.
- `hue` رنگ غالب تصویر محصول است (۰ تا ۳۶۰).

## ۳) تغییر دسته‌ها
در `data.js` آرایهٔ `CATS` را ویرایش کنید. آیکون هر دسته از کتابخانهٔ داخلی است (`cpu`, `shirt`, `home`, `spark`, `activity`, ...).

## ۴) اتصال به بک‌اند واقعی
در `config.js` مقدار `mode` را `'api'` و `apiBase` را آدرس بک‌اند بگذارید. سپس دادهٔ محصولات را به‌جای `data.js` در دیتابیس بک‌اند مدیریت کنید (`backend/db/seed.js` نمونه دارد).

## ۵) گردش‌کار برای هر مشتری
1. از مخزن به‌عنوان **Template** یک مخزن جدید بسازید (Use this template).
2. `config.js` و `data.js` را برای مشتری عوض کنید.
3. روی `main` پوش کنید → دموی Pages خودکار ساخته می‌شود.
4. برای پروداکشن، بک‌اند را دیپلوی و `mode` را `api` کنید.

## نکات
- حالت `demo` هیچ درخواستی نمی‌فرستد؛ مناسب نمایش سریع و بدون سرور.
- تصاویر محصولات وکتور هستند و نیازی به عکس واقعی ندارند؛ برای مشتری نهایی می‌توانید تابع `art()` در `art.js` را با `<img>` جایگزین کنید.
